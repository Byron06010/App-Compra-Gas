# ⛽ Sistema Web de Compra y Gestión de Gas

Aplicación web full-stack desarrollada para la gestión y comercialización de gas, construida con un stack moderno de JavaScript, motor de plantas dinámicas y persistencia de datos en base de datos NoSQL.

---

## 🚀 Tecnologías y Herramientas Utilizadas

* **Entorno de ejecución:** Nodo.js
* **Backend:** Expreso.js
* **Base de Datos:** MongoDB (NoSQL)
* **Motor de Plantillas:** Manillar (Hbs) para el renderizado dinámico de vistas
* **Control de versiones:** Git y GitHub

---

## 📁 Estructura del Proyecto

El repositorio está organizado de la dirección manual:

* `src/` — Continúa la lógica del servicio, rutas, controladores y modelos de la aplicación.
* `img/` — Recursos gráficos e imágenes corporativas utilizadas en la interfaz web.
* `paquete.json` (package.json) — Gestión de dependencias y scripts de arreglo del proyecto.
* `.env` / Configuración — Variables de entorno para la conexión a la base de datos.
